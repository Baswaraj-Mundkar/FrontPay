## Project description

FrontPay is a browser-based UPI QR scanning website designed to let a user scan a QR code using a phone's front-facing camera and then hand the payment URI off to a compatible UPI app. It is intended as an alternative for people whose rear camera is unavailable or damaged.

The project uses HTML, CSS and vanilla JavaScript. QR decoding uses the third-party `jsQR` library.
