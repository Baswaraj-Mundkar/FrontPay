# Code of Conduct

## Our commitment

We want participation in FrontPay to be respectful, constructive and free from harassment, regardless of experience level, background or identity.

## Expected behavior

- Be respectful and considerate.
- Give and accept constructive feedback professionally.
- Focus criticism on ideas and implementation, not individuals.
- Respect privacy. Do not publish anyone's personal information or real payment details.
- Act in the best interests of a safe and useful project.

## Unacceptable behavior

Harassment, threats, discriminatory language, personal attacks, doxxing, sexualised attention, and deliberate disruption of discussions are not acceptable.

## Maintainer responsibility

Project maintainers are responsible for clarifying and enforcing this code. They may remove comments, close discussions or reject contributions that violate it.

## Reporting

Report conduct concerns privately by contacting the repository maintainer through the GitHub profile associated with this project. Do not use public issue reports for sensitive complaints.

This code of conduct applies to project issues, pull requests, discussions and other project spaces.
